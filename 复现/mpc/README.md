# 四足运控复现：从一步力分配到 convex MPC

> **执行**：2026-11-22 · **环境**：WSL2 Ubuntu / Python 3.12.16 / MuJoCo 4.0.1 / RTX 3060 Ti
> **对象**：模型派运控（对应 Di Carlo et al., RA-L 2018 的 convex MPC 思路）
> **结论**：站立达标；小跑能到目标速度但撑不过 3 秒。

---

## 0. 先澄清：这不是论文数字的复现

本轮做了**两版控制器**，都是自建模型（`quad12.xml`，11.2 kg，12 DOF）上的自建实现，**不能与 Cheetah 3 / ANYmal 的报数直接比较**。

| 版本 | 文件 | 结构 | 结果 |
|---|---|---|---|
| v1 | [run_quad.py](run_quad.py) | 一步力分配 + PD（**不是 MPC**） | 站立成功，行走失败 |
| v2 | [convex_mpc.py](convex_mpc.py) | **10 步滚动时域 convex MPC** + WBC | 站立达标，小跑到速但失稳 |

v1 严格说不算 MPC，只是力控；v2 才是论文那条路。

---

## 1. v2：convex MPC 实现

| 项 | 实现 |
|---|---|
| 模型 | 单刚体（SRBM），质量 11.2 kg，惯量 diag(0.035, 0.13, 0.14) |
| 状态 | x = [roll, pitch, yaw, p(3), ω(3), v(3)]，12 维 |
| 动力学 | ṗ=v, v̇=f/m+g, Θ̇=ω, ω̇=I⁻¹Σ(r×f)，每步线性化 |
| 时域 | N=10，dt=0.025 s（40 Hz MPC，500 Hz 关节控制） |
| 约束 | 摩擦金字塔 \|fx\|,\|fy\| ≤ μfz（μ=0.6），0 ≤ fz ≤ 150 N |
| 求解 | OSQP，120 变量，实测 **3.6–4.0 ms**（max 10.8 ms） |
| WBC | τ = −Jᵀf + 支撑腿小增益 PD（kp=5, kd=1.2）+ 摆腿 IK 跟踪 |

## 3. 诊断

### 3.1 踩过的四个真坑（都有数据支撑）

1. **力矩映射符号。** `τ = +Jᵀf` 时 MPC 一直要求上升，机身却沉到 0.17 m；换成 `τ = −Jᵀf` 后高度回到 0.272 m。MuJoCo 的 `jacp` 是 ∂x_site/∂q，于是 τ = Jᵀ F_ext（F_ext 为环境施加在足端的力）。

2. **支撑腿 PD 与 MPC 打架。** kp=80 时 MPC 输出的力被 PD 抵消，2.7 s 翻车；降到 kp=5、kd=1.2 后站立稳、高度抖动 2 mm。

3. **IK 不能直接改 qpos。** 早期版本用 IK 迭代时直接写 `qpos`，等于每 4 ms 给系统注入一次能量，必然发散。改成算完即还原。

4. **摆腿方向。** (1−2s) 写成 (2s−1) 之前，摆动相脚是往前甩的，净位移为负。

### 3.2 为什么还是会翻

- **没有落脚点优化。** 论文用 Raibert 启发式 + 地形信息决定落点，我用固定偏移；横向扰动累积后无处纠正。
- **没有接触力连续性约束。** 支撑相切换瞬间力从 0 跳到 mg/2，模型里没有软过渡。
- **单刚体假设丢掉了腿部动力学。** 摆腿质量 0.75 kg × 4 的甩动在高速下不可忽略。
- **姿态权重与速度权重冲突。** 调大滚转权重能防翻但速度掉到 0.02；调小能跑到 0.38 但侧翻——说明需要**按相位的增益调度**，而不是一组固定权重。

## 4. 复现到什么程度（诚实结论）

| 论文能力 | 本项目 | 说明 |
|---|---|---|
| 单刚体 convex MPC 形式化 | ✅ 完成 | 滚动时域、线性化、摩擦锥 QP |
| 40 Hz 在线求解 | ✅ 完成 | OSQP 4 ms |
| 站立平衡 | ✅ 完成 | 高度误差 3 mm，姿态 <5° |
| 速度跟踪行走 | ⚠️ 部分 | 速度对了，稳定性不足（3 s 就翻） |
| 感知地形 / 落脚点优化 | ❌ 未做 | 平地固定步态 |
| 与论文数字对比 | ❌ 不可比 | 自建模型，非 Cheetah 3 |

## 5. 想继续的话

1. **Raibert 落脚点 + 横向速度反馈**（最可能解决侧翻，改动最小）
2. **按相位调增益**：支撑初期重、末期轻，避免切换冲击
3. **加接触力软约束**：用 slack 变量代替硬约束
4. **换真机模型**：`quad12.xml` 是自建的，质量分布与任何商用狗都不同
