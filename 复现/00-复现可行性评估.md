## 2. 逐项评估

### 2.1 legged_gym（经典主线）

- **仓库**：https://github.com/leggedrobotics/legged_gym
- **硬依赖**：Isaac Gym Preview 4（**需 NVIDIA 开发者账号登录下载**）、Python 3.8、PyTorch 1.13 + CUDA 11.7
- **显存**：论文默认 4096 环境，参考配置在 24 GB 卡上跑；3060 Ti 8 GB 需降到 1024–2048 环境，训练时间同比拉长
- **时间预期**：论文称平地 <4 分钟、崎岖 20 分钟（单卡高端 GPU）。本机降到 1/2–1/4 环境数后，**平地估计 30–90 分钟，崎岖 3–6 小时**
- **风险**：Isaac Gym 已停止维护，与新版驱动/GLIBC 的兼容问题是主要卡点
- **判断**：**值得跑，但本机被下载门槛卡死**

### 2.2 mujoco_playground（本机最现实的路线）

- **仓库**：https://github.com/google-deepmind/mujoco_playground
- **依赖**：纯 pip 安装（`mujoco` + `jax` + `brax`），无 Isaac Gym，无需 NVIDIA 账号
- **显存**：MJX 在 8 GB 卡上跑 1024–2048 环境没问题
- **时间预期**：Go1 速度跟踪任务，单卡 30–90 分钟能看到明显收敛
- **风险**：pypi 下载是唯一门槛；CUDA 版 jax 包体积大
- **判断**：**只要能解决网络，这是唯一能在本机真正跑通的路线**

### 2.3 IsaacLab

- **仓库**：https://github.com/isaac-sim/IsaacLab
- **依赖**：Isaac Sim 4.5+（约 10–15 GB）、Isaac Lab、Python 3.10
- **显存**：Isaac Sim 官方建议 **16 GB 以上**；8 GB 属于「可能启动、随时崩」区间
- **时间预期**：装环境本身 2–4 小时（网络前提下），训练另算
- **判断**：**长期该走，但本机不适合**。若要跑，建议租云 GPU（A10/4090）

### 2.4 convex MPC（不依赖仿真器，可独立复现）

- **做法**：不需要 Isaac。用 Python + OSQP/CasADi 自己写单刚体 MPC，配 MuJoCo 的单腿/四足模型
- **时间**：2–5 天（含调参）
- **价值**：能真正理解 QP 形式化，且不依赖任何闭源组件
- **判断**：**作为「不想碰 Isaac 生态」的替代路线，性价比很高**

---

## 3. 结论

1. **本机当前状态：0 个 baseline 可复现**（缺 Python + 包源不可用 + Isaac Gym 需登录）。
2. **最小可行路径**：装 Python → 配国内镜像 → 跑 mujoco_playground 的 Go1 → 再评估是否上云跑 legged_gym。
3. **不推荐**在本机硬上 IsaacLab：8 GB 显存会让所有时间花在 debug OOM 上，而不是理解方法。
4. 在真正跑通之前，报告里所有指标都应当保持「引自论文」的标注，**不要写成「我们复现得到」**。
