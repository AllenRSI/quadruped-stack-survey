01 — 核心判断

运动控制已经不是瓶颈，
瓶颈转移到了「可靠地理解任务」

2021 年之后，GPU 万级并行 RL 把四足运动控制从「研究课题」变成了「工程配置项」。这改变了整个行业的竞争位置。

判断一

下层已商品化

开源栈（legged_gym / IsaacLab / unitree_rl_gym）让「训练一条能走能跑的策略」的门槛降到几周。差异化不再来自步态，而来自感知鲁棒性与交付可靠性。

判断二

混合架构是现实答案

纯 MPC 对地形敏感，纯 RL 缺安全边界。产业界的真实方案几乎都是「RL 运动基元 + 规划/MPC 给目标」的分层混合，而非二选一。

判断三

VLA 仍在实验室

2025–2026 出现了四足 VLA 论文（MoRE、ODYSSEY），但都是固定场景、有限任务的真机实验，没有一款产品把它当作常态化能力。

「四足 + VLA」目前是一个方向正确但尚未产品化的命题。把它当成既定事实来规划产品，是这次调研里最需要避免的错误。

越往下，延迟越致命

03 — 范式演进

2018 → 2026：
三条主线的交替

模型派 → 学习派 → 混合派。理解这条曲线，才能判断 2026 年该把工程资源投在哪一层。

2018
MIT Cheetah 3 · convex MPC
把四足控制写成标准 QP，单次求解毫秒级。模型派的巅峰，至今仍是很多工业方案的安全底线。
2019
MIT Mini Cheetah · RL 直接学步态
Hwangbo 等（Science Robotics）证明不建模也能走，但 sim2real gap 仍然巨大。
2021
RMA + legged_gym / Isaac Gym
teacher-student 蒸馏 + 单卡 4096 环境并行，把训练从「天」压到「分钟」。开源生态自此爆发，这是整个领域的分水岭。
2022
Walk These Ways · 策略条件化
一个策略通过指令条件切换多种步态，RL 从「能走」走向「可控」。
2023
ANYmal 感知式鲁棒运动（Science Robotics）
首次把外部感知接进 RL 策略，雪地、废墟、动态障碍级别的鲁棒性。感知与运控的边界开始模糊。
2024
Extreme Parkour · HIMLoco · IsaacLab
极限运动能力；历史观测缓解部分可观测；工具链换代，工程门槛继续下降。
2025
π0.5 / GR00T N1 / V-JEPA 2 / Genie 3
通用 VLA 与世界模型进入「可用」区间。同年 MoRE、ODYSSEY 把 VLA 搬上四足，但仍是论文级。
2026
世界模型补数据 · 产业整合
研究热点转向「用生成式模型补训练数据 / 做预测辅助」，产品侧转向可靠性与交付。VLA 仍未见常态化落地。
04 — 宣传 vs 真机

四档可信度：
把 demo 和产品分开

产品里持续运行

有客户交付、有长期运行数据。Spot 巡检、Unitree SDK 运控、ANYmal 工业巡检。

05 — 运动控制

L1：从 convex MPC 到
GPU 并行 RL，再到动作模仿

2021 年之后，这一层经历了从「优化」到「学习」再到「混合」的三段式。但模型派并没有死，它退化成了 baseline 和安全兜底。

派别代表机制换机型成本2026 现状
模型派convex MPC / OCS2简化刚体 + 在线 QP/NLP重辨识、重调权重baseline / 安全兜底
学习派legged_gym + PPO万级并行仿真 + 域随机化重训 + 重调奖励事实标准
混合派MPC 出解 + RL 残差优化器给可行解，网络补残差接口调试为主工业界主力（多闭源）

模型派的天花板

MIT Cheetah 3 的 convex MPC（Di Carlo 等，RA-L 2018）把四足控制写成标准 QP：预测时域 ≤0.5 s、单次求解 <1 ms、控制频率 20–30 Hz，实测 3 m/s 奔跑、1 m/s 侧向、180°/s 转向。它的贡献是把四足从「调参玄学」变成可复现的优化问题。

天花板也很清楚：模型里没建模的东西，控制器永远不会利用——尤其是非结构化地形上的落脚决策。

sim2real：落地失败几乎都发生在这里

动作空间选关节位置目标 + PD，力矩直出对电机常数、摩擦、温漂太敏感。控制频率策略 50 Hz、物理 200 Hz（dt=0.005, decimation=4）。域随机化顺序很重要：先窄后宽——一上来给大范围，策略会学成保守的龟速。

延迟必须当一等公民。动作延迟 1–3 步、观测延迟、50 Hz 下的 20 ms 抖动，都要显式建模。这是「仿真里很好、实机就抖」的头号原因。
2025–2026 最热的两条线（动作模仿、世界模型）在四足上基本还是「搬人形的模块」。四足真正的新进展反倒在感知鲁棒性和规划时域这类更工程的问题上。
06 — 感知与导航

L2–L4：状态估计、高程图与 Nav2

最容易低估的是状态估计，最容易过度设计的是导航。90% 的实机翻车发生在「腿里程计漂了 5 分钟之后，高程图错了 20 cm」。

为什么四足的状态估计比轮式/人形都难

腿既是传感器又是执行器，接触状态每一毫秒都在变，而所有「零速假设」类观测在高动态下失效。

难点机理后果
飞行相 / 腾空小跑/跳跃时无足端接触基座高度不可观——含 flight phase 时 SOTA 方法无法可靠估计 base height
足端打滑leg odometry 假设支撑足相对世界速度为零冰面/碎石直接崩；足端 GRF 对「接触但打滑」不敏感
IMU 饱和落足冲击打满量程，bias 随温度漂移姿态数秒内线性发散
视觉退化运动模糊、低纹理、逆光VIO 在纯旋转/匀速段尺度退化

四条路线与失效模式

方案频率传感器成本主要失效场景
Contact-aided InEKF / Pronto200–1000 Hz极低打滑、飞行相、接触误判
VIO（VINS-Fusion / OpenVINS）20–60 Hz中运动模糊、低纹理、光照突变
VILO 紧耦合（VILENS / Cerberus）10–50 Hz中高视觉与 LiDAR 同时退化
LIO（FAST-LIO2 / Point-LIO）10–50 Hz高长廊/隧道几何退化、雨雾粉尘

正确架构：contact-aided EKF 提供高频鲁棒主干（跟随 IMU，200–1000 Hz）+ VIO/LIO 只做低频漂移校正（10–60 Hz），外加退化检测与模态切换。

最大认知误区：把「狗走不稳/走偏」当成传感器融合调参问题去换更好的 VIO/LIO。加 VIO 不会让飞行相的 base height 变得可观测，换 MPPI 也不会修正 5 分钟后的地图漂移——该修的是接触状态建模和退化检测。

建图不是难点，「什么算可通行」才是。雪、植被、水面在视觉上「像不可踩障碍」，或者干脆没有回波——这是野外感知型运动控制的主要失败源。

盲走与视觉不是二选一。盲走在平地、缓坡、已知台阶上并不差；差距只在负障碍、高台、稀疏障碍、乱石地。正确做法是双模并存 + 按地形置信度切换。

SayTap（Go1）常被归入此类，但它不是 VLA——它是 LLM 输出足端接触模式，没有视觉-语言-动作的联合建模。

为什么四足 VLA 比机械臂难一个量级

机械臂 VLA 可以 5–10 Hz 直出末端增量，因为底座不动、动力学慢。四足不行：机身欠驱动，任何 1 Hz 级指令都必须由 50 Hz 策略去实现、由 500 Hz–1 kHz 的关节 PD 去跟踪。

所以四足的 VLA 输出必然是抽象的：航点、速度指令、skill 选择、接触模式。谁声称 VLA 直出四足 12 维关节且效果好，基本可以直接怀疑。

世界模型的真实位置

DayDreamer（2022）在 A1 真机上约 1 小时学会走路，是腿式上唯一像样的证据，四年无同量级后续。Cosmos 是数据工厂不是控制器；Genie 3 闭源无公开 API，与四足控制无任何公开结合。

结论：世界模型目前在四足上的作用是「补数据」和「辅助预测目标」，不是策略本身。

云深处

公开程度最低

维他动力 / 众擎

公开信息全是产品叙事，零算法细节。众擎 JS01 只有「地形感知动态调步态」一句话。选型时按黑盒整机对待。

一个值得注意的规律：「公开算法栈」和「卖得好」几乎负相关。卖得最多的宇树只开源工具链，云深处只发论文不给代码。

商业模式：钱从哪来

巡检是唯一规模化落地的场景（电力、隧道、化工）。云深处自认行业端四足出货全球第一，但全国 1 万+ 变电站只做了 200+ 个项目——渗透率仍是个位数百分比。

科研教育是宇树的现金牛；安防、娱乐表演是品牌曝光不是可持续收入；To-Developer 的 SDK 生态才是长期护城河，也是评价一家公司的关键指标。

09 — 选型建议

如果你现在要搭一套，
这样选

A · 要做产品（12 个月内交付）

下层用开源栈，上层保持可插拔

L1 IsaacLab 训 RL 策略 → ONNX → 真机 PD 跟踪；L2 厂商状态估计 + 腿里程计融合；L3 深度相机 + 高程图（需要爬楼梯才上）；L4 ROS2 Nav2 + MPPI；L5 不做，用现成 VLM API 包一层任务分发，人兜底。

B · 要做研究（找空白）

skill primitive + 长程任务

真正的空白在二者的交界：怎么把 RL 训出来的运动技能抽象成可组合、可验证、可恢复的原子能力，再让上层模型编排。这个问题在四足上没人做好，且不需要重新发明运动控制。

C · 要入门

四个阶段，5–12 个月

有 ROS/控制基础 5–6 个月，纯新手 10–12 个月。真正决定成败的是阶段 3「实机部署」——60% 的人卡在这里。

硬件选型

场景推荐理由

学习路径

阶段有基础纯新手产出
1 数学与控制基础4 周10 周MuJoCo 手写单腿 VMC 弹跳
2 仿真训练跑通6 周8 周盲走平地+坡道策略，sim2sim 不摔
3 实机部署6–8 周10 周实机 10 分钟不摔、上 15° 坡、扛一次踢腿
4 高层智能8 周10 周语言指令「去 B 区看阀门」并自主到达
阶段 3 的关键认知：90% 的实机摔不是策略问题，是状态估计与时间同步问题——IMU 延迟、关节零位偏差、控制频率抖动。先量这三样，再怀疑网络。
如果你的目标是「把狗卖出去」，阶段 1–3 走完就够；如果你的目标是「研究」，阶段 2 与 4 的交界才是 2026 年真正空白的坑。
