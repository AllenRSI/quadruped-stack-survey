# 04 产业界产品方案与学习路径

> 调研口径：截至 2026-11-18。价格一律标来源与时间；厂商没公开的一律写「未公开」，第三方渠道价标「未核实」。本文只采信**厂商官网/官方公众号/招股与辅导材料/一手媒体**，不接受二手测评号的估算。
>
> 一句话结论：**四足本体的硬件差距在 2025-2026 已经被抹平到「同一代器件、不同价格带」；真正拉开差距的是三件事——运控是否用上了 GPU 并行 RL + sim2real、感知导航是否做到无 GPS 自主巡检、以及 SDK 是否真能让第三方跑通自己的算法。** 而「公开算法栈」和「卖得好」几乎是负相关的：卖得最多的两家（宇树、云深处）一个只开源工具链、一个只发论文不给代码。

**注意**：Dexmal（原力灵机）是独立公司，**不是宇树子公司**，与宇树的关系只是「同处具身智能赛道」。调研中被常混为一谈，此处更正。

**判断**：
1. **公开程度最高：云深处。** 它把「世界模型 + VLA + Agent + 策略优化 + Benchmark」五个模块连名字带数据规模一起发了，还拉了七所高校背书。这在国产四足里是唯一一份能拿去当技术路线图读的材料。但它公开的是**方法**不是**权重**，对二次开发的直接帮助有限。
2. **公开程度最低：维他动力、众擎。** 两家的公开信息全是产品叙事，没有一个字的算法栈。这不是批评——消费级本来就不需要向开发者交代；但选型时要把它们当「黑盒整机」，别指望改运控。
3. **最被高估的是「开源」二字。** 宇树开源的是**接口和训练脚手架**，不是它自家在 B2 上跑的那套策略；真正让第三方跑通自己算法的，是 SDK 稳定性和仿真一致性，这两点宇树仍是国内第一。

**判断**：To B 的钱在「交付」不在「本体」。云深处自认海外收入约 20%、国内 80%（来源：每日经济新闻，2026-05-02），说明国产四足的海外溢价还没跑出来；而它把「200 多个项目 vs 1 万多个变电站」直接讲出来，等于承认行业仍在**创新场景体验阶段**，不是复制粘贴阶段。To D（开发者）的钱是「生态税」：宇树靠 9,997 元起的 Go2 把一代学生变成了用户，这批人毕业后会带着习惯进入工业选型——这是比单台毛利更值钱的资产。

## 4. 2025-2026 趋势判断

1. **从「炫技 demo」到「可靠性交付」。** 指标重心从「后空翻/跳桌子」转向「IP54、-20~55 ℃、50 kg 额定负载跑 2 km」（X50，2026-11）。这是行业成熟的硬信号：参数表开始写工作温度而不是动作名称。
2. **从「遥操作」到「自主巡检」。** 云深处 X30 的卖点是「黑暗、强光、闪烁、无光条件下自主导航」；BD 把 Gemini 接进 AIVI-Learning 做「设施持续学习 + 高阶视觉推理」（2026-04）。共同点：**人从回路里被摘出去**。
3. **资本化窗口打开，头部开始拼财报而非视频。** 宇树 2025 年营收近 17 亿元、2026-06-01 上会（来源：证券日报/新浪财经）；云深处 2025-12 完成数亿元 Pre-IPO（国家人工智能产业基金领投、京东跟投），2026-05 完成辅导（来源：每日经济新闻，2026-05-02）；逐际动力 2025-07 获京东战略领投，2026-07 完成近 2 亿美元 Pre-IPO（来源：创业邦，2026-07）。**京东同时押注云深处与逐际动力**，渠道方在下注。
4. **具身大模型在四足上的商业化仍处于「可演示、难验收」。** 云深处敢把 DR-VLA-2.0 的插头插接、花瓶擦拭进度（78.5%/85.2%）写出来，恰恰说明这些是实验室指标；真正验收的是「巡检漏检率」。**四足上的 VLA 目前是加分项，不是买单理由。**
5. **产品线在向轮足收敛。** Go2-W、B2-W、As2-W、山猫 M20S 全在 2025-2026 出现。原因很朴素：客户要的是「到得了、待得住」，不是「会爬楼梯」。四足正在被降级为「越障模块」，而不是整机形态。

## 5. 学习路径：4 阶段，两条路

先给总账：

| 路径 | 前置要求 | 总时长 | 时间怎么分 | 最容易卡死的地方 |
|---|---|---|---|---|
| **A. 有 ROS/控制基础** | 写过 ROS2 节点、懂 PID/LQR、能读 C++ | **5~6 个月**到「实机跑自己的策略」 | 阶段 1 压到 4 周，阶段 2/3 各 6~8 周，阶段 4 并行 | 阶段 3 的状态估计与时间同步 |
| **B. 纯新手** | 会 Python，线代/微积分生疏 | **10~12 个月** | 阶段 1 占 10 周（补数学+工具），阶段 3 占 10 周 | 阶段 1 想跳过 QP/最优控制，阶段 2 直接抄超参 |

两条路的差别不在阶段数，而在阶段 1 与阶段 3 的投入比例：新手要把 60% 时间花在数学与工具链，老手可以 3 周过掉。

### 阶段 1：数学与控制基础（有基础 4 周 / 新手 10 周）

| 项 | 内容 |
|---|---|
| 必读论文 | ① Raibert, *Legged Robots That Balance*（1986，书，无 arXiv，读第 1-3 章）② Bledt et al., *MIT Cheetah 3: Design and Control of a Robust, Dynamic Quadruped Robot*, IROS 2018（无 arXiv）③ Di Carlo et al., *Dynamic Locomotion in the MIT Cheetah 3 Through Convex Model-Predictive Control*, IROS 2018（无 arXiv，**读它的 QP 形式化**）④ arXiv:1901.08652 *Learning Agile and Dynamic Motor Skills for Legged Robots*（先读，建立「RL 能干 MPC 的活」的直觉）⑤ arXiv:1812.11103 *Learning to Walk via Deep RL*（PPO + 域随机化的原始配方） |
| 课程 | MIT 6.832 *Underactuated Robotics*（Tedrake，免费教材，重点读 HZD/轨迹优化两章）；CMU 16-745 *Optimal Control*（2023 公开课，补 LQR/iLQR/MPC 的数学） |
| 代码 | `OCS2`（leggedrobotics，MPC 全家桶，先读例子不读实现）；`mujoco` 官方 Python 教程（把单腿弹跳搭出来） |
| 产出 | 用 MuJoCo 手写一个单腿 VMC（虚拟模型控制）弹跳，能改刚度/阻尼看到行为变化 |
| 新手补课 | 西北大学 *Modern Robotics*（Coursera）+ 线性代数补到「能看懂 QP 的 KKT 条件」 |

### 阶段 2：仿真训练跑通（有基础 6 周 / 新手 8 周）

| 项 | 内容 |
|---|---|
| 必读论文 | ① arXiv:2109.11978 *Learning to Walk in Minutes Using Massively Parallel Deep RL*（legged_gym 母论文，**必精读**）② arXiv:2108.10470 *Isaac Gym*（理解为什么能万级并行）③ arXiv:2212.03238 *Walk These Ways*（把步态当参数调，工程上极实用）④ arXiv:2107.04034 *RMA: Rapid Motor Adaptation*（teacher-student 蒸馏的起点）⑤ arXiv:2201.08117 *Learning Robust Perceptive Locomotion for Quadrupedal Robots in the Wild*（地形感知进策略）⑥ arXiv:2301.10671 *DreamWaQ*（无特权信息的学生策略）⑦ arXiv:2110.05457 *Legged Robots that Keep on Learning*（在线适应） |
| 课程 | ETH *Robot Dynamics*（Hutter，把 WBC/接触力学讲透）；Berkeley CS285（只读 policy gradient / model-based 两部分） |
| 代码 | `legged_gym` + `rsl_rl`（首选）；`unitree_rl_gym`（想直接上 Go2 就用这个；新项目可换 Isaac Lab） |
| 产出 | 训练一个能盲走平地+坡道的策略，导出 ONNX，在 MuJoCo 里 sim2sim 不摔 |
| 关键坑 | 域随机化范围一开始就给大，策略会「学成保守的龟速」；先窄后宽，逐项加。 |

### 阶段 3：实机部署（有基础 6~8 周 / 新手 10 周）

| 项 | 内容 |
|---|---|
